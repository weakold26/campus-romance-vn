# 도서관 창가 3번 자리

> 시험까지 닷새, 축제까지 나흘. 창가 세 번째 자리에서 시작된 5일.

브라우저에서 바로 하는 캠퍼스 로맨스 비주얼 노벨입니다. 설치 없이 링크만 열면 플레이됩니다.

**플레이: https://weakold26.github.io/campus-romance-vn/**

## 이야기

중앙도서관 3열람실 창가, 세 번째 자리. 1년째 같은 자리에 앉던 주인공 앞에 어느 날 검은 가방 하나가 놓인다.
과 대표 한서윤의 가방이다.

- **한서윤** — 3학년, 과 대표. 말은 짧고 표정은 없지만, 자리를 맡아두고 커피를 말없이 놓고 간다.
- **문채원** — 1학년, 영화동아리 '필름통' 신입. 축제 상영회를 앞두고 밤새 편집하다 책상에 잠든다.

시험기간 5일과 축제 전야. 도서관, 동아리방, 인쇄실, 그리고 축제의 밤.
선택에 따라 다섯 가지 결말에 닿습니다.

## 플레이 방법

| 조작 | 설명 |
| --- | --- |
| 화면 탭 / 클릭 | 다음 대사 (타이핑 중이면 즉시 완성) |
| 숫자 키 1–9 | 선택지 고르기 |
| Space / Enter | 다음 대사 |
| L | 백로그 |
| A | 자동 진행 |
| S | 스킵 |
| Esc | 창 닫기 |

- 자동 저장은 대사마다 갱신되고, 저장 슬롯 3개를 따로 쓸 수 있습니다.
- 엔딩 도감에서 지금까지 본 결말을 확인할 수 있습니다.
- 사운드는 WebAudio로 실시간 합성하며, 장면마다 분위기가 바뀝니다. 첫 탭 이후에 재생됩니다.

## 구성

- 선택지 15개, 엔딩 5종(히든 1종 포함), 대사 노드 799개
- 배경 5종(캠퍼스 낮·도서관·동아리방 노을·축제 밤·강당), 히로인 스탠딩 8장(표정 4종 × 2인)
- 두 캐릭터 동시 연출(화자가 아닌 쪽은 어둡게), 호감도 게이지 2종
- 데스크톱·모바일 반응형, `word-break: keep-all`

## 개발

```bash
# 대사 원고(src) → scenario.json 컴파일
python3 tools/build_scenario.py
# 전수 시뮬레이션 (끊긴 링크·도달 불가 엔딩·오타 패턴)
python3 tools/simulate.py
# 이미지 누끼·정렬·WebP 변환 (원본은 downloads/campus-vn-raw)
python3 tools/build_assets.py
```

- 대사 원고: `tools/script/*.txt` (자체 DSL)
- 이미지: AI 생성 후 누끼·정렬·WebP 변환
- 사운드: 외부 음원 없이 WebAudio 합성
